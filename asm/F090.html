F090: Hide Header Item
Used by the routines at Event_HideHeaderPair, Event_HideHeaderFourth and Event_RevealHeaderTriple.
Hides one header item by overprinting C8.
Hide_HeaderItem F090 LD A,(IX+$00) A=the header record.
F093 AND %01111111 Keep only bits 0-6.
F095 LD C,A C=the column.
F096 SET 7,(IX+$00) Set bit 7 of the header record.
F09A LD B,(IX+$01) B=the row.
F09D CALL JumpTable_SetPrintPosition Call JumpTable_SetPrintPosition.
F0A0 LD B,(IX+$05) B=the remaining height.
Hide_HeaderItem_Target F0A3 LD C,(IX+$04) C=the remaining width.
Hide_HeaderItem_Continue F0A6 LD A,$C8 A=C8.
F0A8 CALL JumpTable_PrintCharacter Call JumpTable_PrintCharacter.
F0AB CALL JumpTable_WriteTile Call JumpTable_WriteTile.
F0AE DEC C Decrease the width and loop back to Hide_HeaderItem_Continue.
F0AF JR NZ,Hide_HeaderItem_Continue
F0B1 DJNZ Hide_HeaderItem_Target Decrease the height and loop back to Hide_HeaderItem_Target.
F0B3 RET Return.
