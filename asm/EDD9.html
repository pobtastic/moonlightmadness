EDD9: Handler: Events
Used by the routine at Dispatch_Events.
Dispatches the event ID in A to a room action. Bit 7 marks a collectible pickup.
Input
A Event ID (bit 7 set for a collectible)
IX Player entity (unused)
Stash the caller context.
