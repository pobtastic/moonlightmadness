D826: Read Kempston
Used by the routines at Initialise_Game, Game_Loop, Controls_Kempston and Controls_Kempston_Climb.
Reads the Kempston port twice and returns with the Z flag set if the two reads match.
Output
A Kempston port value
F Z flag set if the two reads match
Read_Kempston D826 IN A,($1F) Read from the Kempston joystick port twice.
