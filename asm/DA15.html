DA15: Print Key Bar
Used by the routines at Change_Room and Handler_InventoryItems.
Draws the 10 collected-key icons along the bottom of the screen.
Set the icon font and print position.
Print_KeyBar DA15 LD HL,$7C70 Write Buffer_ActiveFont to *CHARS.
DA18 LD ($5C36),HL
DA1B LD BC,$0119 Call JumpTable_SetPrintPosition at column 19 row 01 (the bottom line).
DA1E CALL JumpTable_SetPrintPosition
Start the key loop.
DA21 LD B,$00 Start at key 00.
DA23 LD A,$07 Write WHITE to *ATTR_T.
DA25 LD ($5C8F),A
Skip the highlight unless this key matches *CollectedKeys.
Print_KeyBar_Loop DA28 LD A,($64A1) Jump to Print_KeyBar_Glyph unless this key matches *CollectedKeys.
DA2B CP B
DA2C JR NZ,Print_KeyBar_Glyph
Highlight this key.
DA2E LD A,$38 Write BLACK to *ATTR_T.
DA30 LD ($5C8F),A
Print_KeyBar_Glyph DA33 LD A,$E4 Print key glyph E4.
DA35 CALL JumpTable_PrintCharacter
DA38 INC B Jump to Print_KeyBar_Loop until 10 keys are printed.
DA39 LD A,B
DA3A CP $10
DA3C JR NZ,Print_KeyBar_Loop
DA3E RET Return.
