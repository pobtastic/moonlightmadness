Game Active Flag
00 on the introduction/menu. FF after the intro timeout so Initialise_Game starts a game.

16-bit countdown used by the introduction and demo timeout.

Sound Flags

Sound Duration

Skip Delay Flag
When set, Play_Tune returns through the delay routine instead of playing a note.

Game Complete Flag
Set to FF by Handler_Housekeeping when the combination is complete (every CollectionSlots digit is 09).
647E 1
Control Method
00 is keyboard. Non-zero selects Kempston (and the define-keys highlight).

User-Defined Keys
Five KEY_SCAN codes copied from Table_DefaultKeys. Order: left, right, up, down, action.

Saved Keys

Action Timer

Climb Row

Carried Object
Bit 7 set means nothing is being carried. Drawn by Handler_CarriedObject.
649F 1
Event Timer
Counts down; when it hits 00 Handler_EventTimer fires *PendingEvent.
64A0 1
Pending Event
64A1 1
Collected Keys
Number of keys collected. Print_KeyBar highlights this slot.
64A2 1
Current Room
Room IDs run from 00 to 16.
64A3 1
Temporary Room
64A4 14
Player
Player entity used as IX by Handler_Player.
64B2 2
Random Number Seed
64B4 1
Player Lives
Initialised to 04 by Unpack_Rooms.
64C1 4
Collection Slots
Four combination digits shown on room 00. 09 in every slot is the completed combination and sets GameCompleteFlag.
64C5 50
Table: Room Data
One pointer per room, filled by Unpack_Rooms from Data_Rooms.
64F7 6009
Buffer: Unpacked Rooms
Working copy of the 17 packed rooms. See Unpack_Rooms.
D888 1
Demo Room Count
Remaining demo rooms before returning to the menu.
DAC3 1
Pendulum Position
Pendulum sprite ID for rooms 0A and 0B. FF resets at Handler_Pendulum.
DAC4 1
Pendulum Delta
Added to Pendulum_Position each step. Negated at each end-stop.
